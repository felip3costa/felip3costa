## Personal Projects

### [Open OTS Tray](https://github.com/felip3costa/openotstray)

[![Build](https://github.com/felip3costa/openotstray/actions/workflows/build.yml/badge.svg)](https://github.com/felip3costa/openotstray/actions/workflows/build.yml)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://github.com/felip3costa/openotstray/blob/main/LICENSE)

A Windows system tray app for generating [OneTimeSecret](https://onetimesecret.com) links without ever leaving your desktop. Built to turn "share this password securely" from a multi-tab chore into a single click.

Runs entirely from a borderless flyout anchored near the system tray — no browser, no separate windows:

- **Quick One Time** — paste any text, get a self-destructing link back in one click.
- **Generate** — batch-create random passwords, each with its own one-time link, TTL, and optional passphrase.
- **Latest Link** — history of everything you've shared, with a lock icon that flips automatically once a link has been opened, plus one-click copy and a "Send Email" action with a customizable template.
- **Local history you can actually trust** — link metadata persists across restarts, but the link itself is encrypted at rest with Windows DPAPI (tied to your user account and machine), and passwords/passphrases are never written to disk at all — only kept in memory for the running session.
- Settings loaded from disk are re-validated against safe defaults every time, so a corrupted or tampered config file can't silently redirect requests elsewhere.

Ships as a single framework-dependent `.exe`, built and released automatically by GitHub Actions on every version tag — no manual build step to cut a release.

**Stack:** C# · WPF · .NET 10 · zero external NuGet dependencies (WPF, WinForms' `NotifyIcon`, `HttpClient`, `System.Text.Json`, DPAPI — all straight from the SDK)
